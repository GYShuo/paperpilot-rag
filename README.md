# PaperPilot-RAG

A research paper question answering system based on
Retrieval-Augmented Generation (RAG).

## Overview

PaperPilot-RAG aims to build an intelligent academic
assistant that can understand research papers, retrieve
relevant evidence, answer questions, and compare multiple
research papers with evidence citations.

## Core Features

- Academic paper ingestion
- PDF parsing and document chunking
- Dense retrieval
- BM25 sparse retrieval
- Hybrid search
- Reranking
- Evidence-grounded generation
- Multi-paper question answering
- Retrieval and answer evaluation

## Tech Stack

- Python 3.11
- PyTorch
- BGE-M3
- FAISS
- BM25
- FastAPI
- Streamlit
- LangGraph
- RAGAS
- Pytest

## Dataset

QASPER: A Dataset for Question Answering on Research Papers.
